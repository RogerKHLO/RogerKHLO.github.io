### The Brief
Simulate a robot drawing a custom shape: the letters **T, E, S, T**, each on its own inclined face of a four-sided pyramid. The aim was to join CAD modelling to robot path planning and simulation, and to see how well the setup copes when the environment changes.

### The CAD Model
The letters were designed on the sloping faces in **SolidWorks** and exported as a `.sat` file for import into **ABB RobotStudio**. Each letter is centred on its own triangular plane, and the four planes meet at a central apex at [300, 400, 50].

![Top-down view of the TEST letters on the pyramid with the toolpath](images/projects/220526-topdown.png)

**Smooth curves:** importing the `.sat` file initially tessellated the curves, especially the "S". Setting the wireframe and high-quality HLR/HLV resolution to maximum under Document Properties before export kept the curves smooth instead of broken into straight segments.

### Pen Lifting and Apex Transitions
The four letters sit on disjointed planes, so the pen cannot draw continuously and has to lift between letters. To avoid clipping the pyramid and to keep the program simple, every jump between characters goes through the apex: the tool lifts, moves to the apex, then lowers onto the next letter. This gives clearance and a consistent reference point across the different slopes.

![The pen tool lifting up between letters](images/projects/220526-penup.png)

### Path Planning in RAPID
The targets and transition logic from the station are synchronised to RAPID, and a main procedure runs a path procedure for each character in the order T, E, S, T. Zones were set to **fine** so the tool follows the letter contours exactly, with **MoveL** for straight strokes and **MoveC** for curves.

### Robustness to Changes
If the part is moved, fixed paths would no longer line up. The paths were trained with **AutoPath** against a **workobject** at the top-left corner of the table, which acts as the user coordinate system. Re-aligning that workobject moves the whole TEST path and the apex reference together, as long as the new position is within the robot's reach.

![The pyramid on the table, with the workobject at the table corner](images/projects/220526-table.png)

### The Result
CAD design and robot simulation worked together to draw TEST on an inclined pyramid. The apex worked as the clearance and return point for every transition, tessellation and contouring problems were handled through export settings, fine zones and the right motion commands, and the paths stayed adjustable through the table-corner workobject without reprogramming targets.
